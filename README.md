# 抖音工作台

用于评论采集、信息整理与 AI 文案辅助的桌面工具。

![工作台](docs/images/workspace.png)

## 功能

- 搜索主题、浏览视频并采集评论。
- 筛选和整理评论，导出 CSV 或 JSON。
- 根据主题和评论生成候选文案，人工检查后使用。
- 管理评论与私信文案，设置发送上限。
- 调整任务参数、查看连接状态和运行日志。

## 开始使用

从 [版本下载](https://github.com/CHLACB/douyin-workbench/releases/latest) 获取成品，完整解压后运行 `抖音自动化启动器.exe`。需要 Windows x64 和 Google Chrome。

连接浏览器并登录后，即可搜索和采集。使用 AI 功能前，请在设置中填写自己的模型服务和 API Key。

[使用说明](docs/USAGE.zh-CN.md) · [开发说明](docs/DEVELOPMENT.zh-CN.md)

## 使用说明

登录状态与配置保存在本机。AI 生成会将主题、模板及最近 20 条评论发送到所配置的模型服务，输出需要人工复核。评论和私信发送需要显式启用。

请在有权限的场景下使用并遵守平台规则。本项目与抖音官方无关联。
